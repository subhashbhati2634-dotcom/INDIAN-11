
# India 11 — Android Demo

This is a starter Flutter app for the India 11 cricket-fantasy-style demo.

## Run
1. Install Flutter SDK and Android Studio on a computer.
2. Extract this project.
3. Open the project in Android Studio or VS Code.
4. Run:
   flutter pub get
   flutter run

## Build Android APK
flutter build apk --release

The current version is a non-money demo. It does not include deposits, withdrawals, cash contests, or payment processing.
